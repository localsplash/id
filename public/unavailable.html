Every setting this service needs — the identity database, the trusted network, the OAuth credentials — lives in the NocoDB base IdentityBase, table auth_tbl_Settings. The base is found by name, so a renamed base looks exactly like a missing one.

  • Is NocoDB up, at the URL this service was given?

  • Is there exactly one base with that name — not zero, not two?

Retrying re-detects the base from scratch — no restart is needed once the base is back. A change made in NocoDB reaches this service within 30 seconds on its own.
